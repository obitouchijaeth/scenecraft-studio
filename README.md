# SCENECRAFT

Abre `index.html` en cualquier navegador moderno. No requiere instalación, servidor ni cuenta. Los proyectos se guardan en el navegador y pueden exportarse como JSON y como hoja de producción.

## Entrega

- Aplicación web offline.
- Biblioteca de hooks y estructuras.
- Guía de rodaje vertical.
- Plantillas de guion y revisión.
- Archivos de ejemplo.
