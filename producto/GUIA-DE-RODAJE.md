# Guía de rodaje vertical

## Antes de grabar

1. Escribe una sola promesa para el video.
2. Coloca el cambio visual más fuerte dentro de los primeros dos segundos.
3. Alterna cada 2–4 segundos entre rostro, detalle, pantalla, texto o demostración.
4. Graba dos versiones del hook y una toma limpia sin voz para transiciones.

## Durante el rodaje

- Bloquea exposición y enfoque.
- Deja dos segundos de silencio antes y después de cada toma.
- Mantén textos lejos de los bordes superior e inferior.
- Marca cada toma como: lista, alternativa o pendiente.

## Revisión

- ¿La promesa se entiende sin audio?
- ¿Cada escena aporta información nueva?
- ¿El cierre indica una sola acción?
- ¿El primer fotograma despierta curiosidad?
