# Estructuras incluidas

## Demostración relámpago — 20 s

Hook visual → problema concreto → proceso en tres golpes → resultado → acción.

## Historia de transformación — 35 s

Antes → tensión → descubrimiento → prueba → después → invitación.

## Opinión con evidencia — 45 s

Postura → contexto → tres evidencias → objeción → conclusión memorable.
